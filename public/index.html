⚙️ Persistent Storage Configuration

⚠️ In-Memory Mode Warning:
Hajar App is currently operating in in-memory mode because MongoDB is disconnected. Records entered in this mode reside in server memory and disappear on server restart.

How to Enable Persistent Storage:

  1. Create a free cloud database cluster at MongoDB Atlas.
  2. In MongoDB Atlas: under Security > Network Access, allow access from IP 0.0.0.0/0.
  3. Under Database Access, create a database user and password.
  4. Copy your connection URI and update MONGODB_URI in your .env file: 
    MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/hajar_app
  5. Or run local MongoDB: mongodb://127.0.0.1:27017/hajar_app

💡 Tip: You can export your current data anytime using Export Backup in Settings and restore it once your MongoDB database is connected.
